# To-Do List

Aplikasi daftar tugas (to-do list) sederhana berbasis web yang dibangun menggunakan HTML, CSS, dan JavaScript. Tampilan menggunakan Bootstrap 5. Seluruh data tugas disimpan di dalam array JavaScript.

## Fitur

- **Tambah tugas (Create)**
- **Lihat daftar tugas (Read)**
- **Edit tugas (Update)**
- **Tandai selesai**
- **Hapus tugas (Delete)**
- **Mass Action**
- **Generate Data dummy**

## Struktur Folder

```
uji/
├── index.html   # Struktur halaman dan komponen UI
├── style.css    # Styling tambahan di luar Bootstrap
├── script.js    # Logika aplikasi: data array, CRUD & aksi lainnya
└── README.md    # Dokumentasi projek
```

## Cara Menjalankan

1. Clone atau unduh folder projek ini.
2. Buka file `index.html` langsung di browser (klik dua kali, atau klik kanan lalu pilih Open With browser pilihan).

> Catatan: data disimpan hanya di memori (array), sehingga akan hilang ketika halaman dimuat ulang.
